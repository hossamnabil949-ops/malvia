# تقرير التعديلات — MALVIA

## تم تعديله في نسخة العمل
- إزالة زر دخول المالك من بوابة تفعيل المحل، وإزالة شاشة روابط الإدارة من واجهة المحل.
- جعل لوحة المالك تظهر فقط على المسار `/owner`، دون زر أو رابط داخل نظام المحل. أضيفت إعادة توجيه SPA في `vercel.json` حتى لا يفشل فتح المسار مباشرة عند النشر على Vercel.
- إزالة وصول الإدارة من روابط query/hash القديمة مثل `?admin=owner` و`#admin`.
- إلغاء واجهة حجز القطع والبدائل من المخزون والكاشير، مع الإبقاء على مخطط البيانات القديم فقط لتجنب حذف بيانات سابقة تلقائيًا.
- إزالة تكرار إدارة موديلات السيارات من الإعدادات، والإبقاء عليها في المخزون.
- إخفاء التصنيف والوسوم الخاصة بمنتجات الشاشات من واجهات المخزون والكاشير ونماذج الاستيراد، مع الحفاظ على حقول التوافق القديمة لتفادي كسر البيانات المستوردة.
- ربط شاشة الموردين بسجل دفعات الموردين المحفوظ، وإضافة تسجيل الدفعات وتحديث إجمالي المدفوع والرصيد المؤجل، وربط حركة السداد بالخزينة.
- تحديث رصيد المورد عند تسجيل فاتورة مشتريات، وربط مرتجعات الموردين بسجل مرتجعات المشتريات.
- إزالة رموز الدخول العامة الثابتة للمالك؛ عند وجود رمز افتراضي قديم، يطلب إنشاء رمز قوي جديد.

## نتائج الفحص
- نجح فحص الصياغة (Syntax) لجميع ملفات TypeScript وTSX.
- لا توجد استيرادات محلية مفقودة داخل `src`.
- تعذر إجراء بناء كامل (`npm run build`) لأن تثبيت الاعتماديات لم يكتمل في بيئة الفحص بسبب انتهاء المهلة. لذلك يلزم تشغيل `npm install` ثم `npm run build` في بيئة المشروع قبل النشر.

## قيود مهمة قبل الاستخدام التجاري
- المشروع المرفق واجهة React تحفظ معظم البيانات في `localStorage`؛ لذلك إخفاء مسار المالك ليس عزلًا أمنيًا كاملًا. يلزم Backend وقاعدة بيانات ومصادقة وصلاحيات على الخادم، كما يلزم فصل لوحة المالك إلى تطبيق/نطاق مستقل إذا كان المطلوب عزلًا حقيقيًا.
- لا يمكن تحديد سبب خطأ HTTP 403 بشكل نهائي من ملفات المصدر وحدها؛ يجب اختبار الرابط الفعلي الذي يعطي 403 ومعرفة جهة الاستضافة والصلاحيات. ملف `vercel.json` يعالج مسارات التطبيق الداخلية فقط ولا يصلح صلاحيات Google Drive/Google Cloud أو رابطًا خارجيًا محجوبًا.
- راجع حسابات الموردين بعد النقل باستخدام نسخة بيانات اختبار، ولا تستخدم النسخة المعدلة على بيانات مالية حقيقية قبل إكمال البناء والاختبار التشغيلي.
