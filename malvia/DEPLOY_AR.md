# تشغيل مالفيا على Vercel (كمبيوتر + موبايل، بيانات متزامنة)

## 1) ارفع المشروع
- ارفع الفولدر على GitHub (أو شغّل `npx vercel --prod` من جواه).
- في Vercel: New Project ← اختار المشروع (Framework = Vite، الباقي تلقائي).

## 2) اربط قاعدة البيانات (مرة واحدة)
- Vercel ← مشروعك ← Storage ← Create ← **Neon (Postgres)** ← Connect.
- ده بيضيف `DATABASE_URL` تلقائياً. الجدول بيتعمل لوحده أول طلب.

## 3) متغيرات البيئة (Settings ← Environment Variables)
| الاسم | القيمة |
|---|---|
| `ADMIN_TOKEN` | كلمة سر طويلة لك أنت بس (لوحة المالك `/owner`) |
| `GEMINI_API_KEY` | مفتاح Gemini (للمساعد الصوتي) — اختياري |

بعد إضافتها اعمل Redeploy.

## 4) سجّل أول محل
- افتح `https://اسم-مشروعك.vercel.app/owner` ← هيطلب `ADMIN_TOKEN` ← أضف المحل واحفظ.
- الترخيص بيتحفظ في السحابة، فأي جهاز يكتب المفتاح يلاقيه.

## 5) الاستخدام
- **كمبيوتر:** افتح اللينك في Chrome/Edge ← أيقونة التثبيت في شريط العنوان.
- **موبايل:** Android: Chrome ← "تثبيت التطبيق". iPhone: Safari ← مشاركة ← "إضافة إلى الشاشة الرئيسية".
- سجّل دخول بنفس مفتاح الترخيص على الجهازين. الشاشة بتتحدث كل ~15 ثانية، وبتشتغل أوفلاين وتزامن لما النت يرجع.

## ملاحظات أمان قبل بيع النظام لعملاء
- كلمات مرور الموظفين محفوظة داخل بيانات المحل (غير مشفرة) والتحقق بيحصل في المتصفح. المرحلة الجاية: تسجيل دخول من الخادم مع تشفير كلمات المرور.
- أزرار الدخول السريع (admin/123456) والمفتاح التجريبي `MALVIA-PRO-2026-EG01` للتجربة فقط، احذفهم قبل التسليم.
- صور المنتجات المخزنة base64 جوه البيانات تكبّر الحجم؛ الأفضل لاحقاً رفعها على Vercel Blob.
